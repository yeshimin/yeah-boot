- `待处理`：需求已经明确，可以安排实现。

- `暂缓`：当前明确不实施，满足重新启动条件后再评估。

## 已完成基线

以下能力已经完成，不再作为待办项重复记录：

- 查询条件字段白名单和 SQL 注入风险收口。
- 文件、存储引用删除保护和强制删除确认。
- 接口响应与日志敏感数据脱敏。
- 逻辑删除时自动填充删除时间。
- 登录限流、错误次数锁定与解除登录限制。
- 请求 Trace ID。
- 鉴权资源查询性能优化。
- 用户、角色、组织、岗位等删除关联检查。
- 用户 Excel 模板、导入和导出。
- 首页、项目 README、字段类型和代码生成器整理。
- Maven 依赖、通用 CRUD 文档和后端代码清理。
- 系统参数管理、Redis 缓存和手动刷新。
- JWT + Redis 服务端 Token 校验、在线数量策略和强制下线。
- 视图权限与接口权限标识规范化：分别使用 `view:`、`api:` 前缀，鉴权仍为扁平字符串匹配。

## 维护规则

1. 新增未完成事项时，必须说明范围、当前状态和重新启动条件。
2. 暂缓不代表取消；重新启动时先核对现有代码和数据模型，避免按旧结论直接实现。
3. 完成事项后从“当前事项”移除，并在“已完成基线”或对应开发日志中记录结果。
4. 不在本文档中记录账号、密码、Token、密钥、连接信息等敏感内容。
